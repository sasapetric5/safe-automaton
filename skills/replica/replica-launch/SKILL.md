# Launch readiness
1. Confirm scope and acceptance criteria.
2. Verify content, links, responsive behavior, accessibility basics, security boundaries and docs.
3. Include deliverable manifest, sources, tests, limitations and unresolved findings.
4. Remove secrets and private data; label drafts and unverified claims.
5. Confirm recovery steps and the human release owner.
6. Return READY, READY WITH WARNINGS or BLOCKED with evidence.
7. A readiness report does not authorize publication.
