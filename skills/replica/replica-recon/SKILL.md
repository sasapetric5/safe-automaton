# Recon
1. Confirm repository, branch, commit, environment, task and scope.
2. Inspect docs, pages, functions, tests, configuration and relevant history.
3. Inventory capabilities as present, partial, missing or unverified.
4. Reproduce issues with exact steps, inputs, outputs and evidence where possible.
5. Prefer read-only inspection; do not infer unseen code is absent.
6. Deliver evidence table, unknowns, risks and smallest next step.
7. Stop if target branch or environment is ambiguous.
