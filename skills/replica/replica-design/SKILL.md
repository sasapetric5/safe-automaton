# Design
1. Design for Android-first use, readable contrast, clear labels and keyboard access.
2. Every action needs idle, working, success and actionable failure states.
3. Avoid endless spinners; use bounded timeouts and recovery paths.
4. Prevent duplicate submissions and preserve input after recoverable failures.
5. Distinguish draft, verified, approved and published states.
6. Check focus order, touch targets and responsive layout.
7. Define testable UI acceptance criteria, not only visual opinions.
